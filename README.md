# 🛍️ NexaMart

A modern Django-based E-Commerce web application that provides a seamless online shopping experience with authentication, cart management, wishlist, product reviews, coupons, and order management.

---

## 🚀 Features

### 👤 User Authentication
- User Registration
- Login & Logout
- Account Profile

### 🛒 Shopping
- Product Listing
- Product Details
- Categories
- Search Products
- Add to Cart
- Update Cart
- Remove from Cart

### ❤️ Wishlist
- Add Products to Wishlist
- Remove from Wishlist

### ⭐ Reviews & Ratings
- Submit Product Reviews
- Star Ratings
- Average Rating Display

### 🎟 Coupons
- Apply Discount Coupons
- Automatic Price Calculation

### 📦 Orders
- Checkout
- Cash on Delivery
- Online Payment (Demo)
- My Orders
- Order Details
- Order Status Tracking

### 👨‍💼 Admin Panel
- Manage Products
- Manage Categories
- Manage Orders
- Manage Coupons
- Manage Reviews

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yafiathana-max/NexaMart.git
```

Move into the project

```bash
cd NexaMart
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Install Dependencies

```bash
pip install django pillow
```

Run Migrations

```bash
python manage.py migrate
```

Run Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
