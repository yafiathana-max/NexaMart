# 🛒 NexaMart - Django E-Commerce Website

## 📌 Project Overview

NexaMart is a full-stack E-Commerce web application developed using Django. 
It provides users with an online shopping experience with features like user authentication, product browsing, shopping cart, wishlist, and order management.

This project demonstrates backend development, database management, and full-stack web development skills.

---

## ✨ Features

### 👤 User Features
- User Registration
- User Login & Logout
- User Authentication
- Profile Management

### 🛍️ Shopping Features
- View Products
- Search Products
- Filter Products by Category
- Add Products to Cart
- Wishlist Management
- Place Orders

### 🔐 Admin Features
- Admin Dashboard
- Manage Products
- Manage Users
- Manage Orders
