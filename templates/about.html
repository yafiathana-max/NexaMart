ℹ️ About NexaMart

Welcome to NexaMart

NexaMart is a modern e-commerce platform built using Django. It provides customers with a seamless shopping experience, secure checkout, wishlist management, product reviews, coupons, and order tracking.

This project demonstrates full-stack web development concepts including authentication, database management, pagination, search, filtering, admin dashboard, and responsive UI design.

Our Mission

To provide customers with quality products at affordable prices while delivering a smooth online shopping experience.
